CampusTask 🎓

Deskripsi Proyek

CampusTask merupakan website manajemen tugas kuliah yang dikembangkan untuk membantu mahasiswa mencatat, mengatur, dan memantau penyelesaian tugas akademik. Website ini dibuat sebagai proyek TecFest 2026 Divisi Software Engineering dengan tema *Campus Solution Sprint: Solving Campus Problem with Software*.

Latar Belakang

Mahasiswa sering menghadapi beberapa tugas dengan tenggat waktu dan tingkat prioritas yang berbeda. Kondisi tersebut dapat menyebabkan tugas terlupakan atau penyelesaian tugas menjadi kurang terorganisasi. CampusTask dikembangkan sebagai solusi sederhana untuk membantu mahasiswa mengelola tugas secara lebih terstruktur.

Fitur Utama

1. Menambahkan tugas kuliah.
2. Menentukan tanggal pengumpulan tugas.
3. Mengatur prioritas tugas (tinggi, sedang, dan rendah).
4. Menandai tugas yang telah selesai.
5. Membatalkan status penyelesaian tugas.
6. Menghapus tugas.
7. Menampilkan statistik jumlah tugas.
8. Menyimpan data menggunakan *localStorage* pada browser.

Teknologi yang Digunakan

- HTML untuk membangun struktur halaman.
- CSS untuk mengatur tampilan website.
- JavaScript untuk menjalankan fitur interaktif.
- localStorage untuk menyimpan data pada browser.
- GitHub untuk mengelola versi kode dan kolaborasi.

Cara Menjalankan Website

1. Unduh atau clone repository CampusTask.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan file `index.html` melalui browser.
4. Klik tombol Mulai Sekarang untuk menuju dashboard.
5. Tambahkan dan kelola tugas melalui halaman dashboard.

Batasan Sistem

CampusTask saat ini merupakan MVP berbasis website. Data tugas tersimpan secara lokal di browser sehingga belum tersinkronisasi antarperangkat atau antarpengguna. Website ini belum menyediakan sistem akun dan database online.
